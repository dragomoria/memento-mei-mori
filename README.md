# Memento Mei, Mori

HoloJam #6 entry — Theme: Love and Angst Presented at DSW University game conference.
Completed solo in ~3 days after inheriting the project mid-development.

## About
Visual novel with Undertale-inspired bullet hell combat segment.
Player dodges attacks while collecting feathers - 20 feathers collected = win condition.
Feathers also serve as extra lives.

## What I built
Inherited project with 3 existing scenes, built remaining ~95% of the codebase solo under jam deadline pressure.

## Tech
Unity · C#
